설치 방법 (갤럭시 기준)

  1. 위 버튼으로 APK 파일을 다운로드합니다.
  2. 다운로드 완료 알림 또는 파일함(내 파일)에서 다운로드된 apk 파일을 엽니다.
  3. "출처를 알 수 없는 앱" 관련 팝업이 뜨면 허용을 눌러줍니다. (최초 1회만)
  4. 설치를 눌러 설치를 완료합니다.
  5. 홈 화면에 생성된 퇴근셔틀 아이콘을 실행합니다.
⚠️ 앱이 이미 설치된 상태에서 새 버전을 설치할 때도 동일한 방법으로 다시 다운로드 후 설치하면 기존 앱 위에 업데이트됩니다.

안내

  1. 탑승 명단은 매일 자동 초기화됩니다.
  2. 탑승/미이용 등록 내용은 전원에게 실시간으로 공유됩니다.
  3. 문제가 있을 경우 담당자에게 문의해 주세요.
